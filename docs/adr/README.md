# Архітектурні рішення (ADR)

Нормативні рішення Sokol-Core: що гарантує система, чому саме так і коли це треба
переглянути. Поточну реалізацію описує [ARCHITECTURE.md](../../ARCHITECTURE.md), а ADR —
контракти, на які вона спирається. Кожен ADR самодостатній: для розуміння не потрібні
приватні матеріали.

**Статуси.**
- *Реалізовано* — код і тести відповідають рішенню; формальне прийняття за власниками.
- *Прийнято* — власники підтвердили.
- *Замінено* — посилання на наступника.

Зміна контракту — це новий ADR або нова ревізія наявного з датою, а не мовчазна правка.
