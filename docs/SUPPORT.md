# Профіль підтримки

**Стан:** 2026-09-27, Pilot / Active Testing. Релізу немає, тож цей профіль описує, **на чому
Sokol-Core перевірено**, а не гарантію. «Перевірено» означає, що автоматична перевірка проходить
на цьому середовищі й тепер. Решта — або очікування з обґрунтуванням, або «не перевірено».
Змінюйте документ разом із тим, що справді перевіряється.

## 1. Перевірено

Кожен прогін CI і кожен PR проходить збірку, модульні тести, clippy, XDP smoke (понад 130
живих перевірок у мережевих просторах імен на veth) і демо на 3 вузли.

| Середовище | Архітектура | Ядро | Де |

| Ubuntu 24.04 у VM colima (Apple Silicon), привілейований Docker | aarch64 | 6.8 | локальні прогони розробника |

## 2. Очікується, але не перевірено

| Що | Чому очікується | Що зробити перед пілотом |
|---|---|---|
| Ядра 5.15–6.7 | README вимагає 5.15+: LPM-дерево, per-CPU масиви, ringbuf (5.8+), `CAP_BPF`/`CAP_PERFMON` (5.8+) | smoke на цільовому ядрі |
| Інші дистрибутиви з systemd | залежності — ядро й libc | smoke на цільовому дистрибутиві |
| Справжні мережеві карти в режимі `native` | XDP-драйвери основних карт (mlx5, ice, i40e, ixgbe, virtio_net) | вимір на цільовій карті: pps, затримка, CPU |
| Фізичні ARM-пристрої | CI на aarch64 зелений | smoke на пристрої |

## 3. Не перевірено й не підтримується

- Години безперервної роботи під навантаженням (soak), дрейф пам'яті й дисків.
- Меш понад кілька вузлів; неповний меш (заявки не ретранслюються).
- Мережеві карти без XDP-драйвера у режимі `native` (лише `generic`, повільніше).
- SELinux/AppArmor із власною політикою, контейнерні оркестратори.
- Годинники вузлів без синхронізації: `expires_ms` абсолютний, вікно конвертів ±30 с
  (ADR-0003). **NTP/chrony обов'язкові.**
- Змішаний меш версій протоколу (v1 і v2), відкат без відновлення ключа й стану разом
  (ADR-0010).

## 4. Вимоги до вузла

- Linux з XDP, systemd, root лише для встановлення (служба працює як `sokol`).
- Синхронізація часу (NTP/chrony).
- Файлова система для `/var/lib/sokol` з `fsync` і атомарним `rename` (ext4, xfs).
- Для Flowspec — gobgpd, що має BGP-сесію з маршрутизатором; для мешу — TCP 7946 між усіма
  вузлами (бажано через WireGuard).

## 5. Як перевірити свій профіль

```shell
sudo scripts/xdp-smoke.sh target/release/orchestrator   # понад 130 живих перевірок
sudo DEMO_AUTO=1 demo/demo.sh target/release            # 3 вузли, зловмисник, чужий вузол
```

Якщо все зелене на вашому ядрі й архітектурі, додайте рядок у таблицю §1 разом із тим, як
саме перевіряли.
